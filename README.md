# Bangladesh Crime Data Profiling

## Project Overview

This project focuses on Automated Exploratory Data Analysis (EDA) and comprehensive data profiling of a Bangladesh Crime Dataset using Python and YData Profiling.

The objective is to explore the dataset, understand variable characteristics, identify data quality issues, examine relationships among variables, and generate an interactive HTML report for detailed analysis.

## Dataset Information

- **Dataset:** Bangladesh Crime Dataset
- **Records:** 1,147
- **Variables:** 49
- **Format:** CSV
- **Data Profiling:** YData Profiling

## Key Features

The automated EDA report provides the following analytical sections:

- **Dataset Overview:** Summary statistics and general dataset information.
- **Variable Analysis:** Detailed information about individual variables and their distributions.
- **Interactions:** Exploration of relationships between variables.
- **Correlation Analysis:** Identification of correlations among numerical features.
- **Missing Values Analysis:** Examination of missing data patterns.
- **Sample Data:** Preview of dataset records.
- **Data Quality Alerts:** Identification of potential data quality issues, including constant values and highly correlated variables.
